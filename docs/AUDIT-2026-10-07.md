# Contract review, 7 October 2026: findings and what was done

Arc Studio reviewed `JobVault.sol` and `AuditAnchor.sol` (13 findings: 2 high, 4 medium, 4 low, 3 informational) and found no way for an outside party to take money. Each finding was checked against the code and against how Bursar uses the contracts. Some were right, some were right about a behaviour but not about its cost, and a few suggested fixes that would have made things worse. This is the result, finding by finding.

## What changed

- **Contract source** (`contracts/src`): a refund that arrives after a job is closed now goes to the owner (JV-01); a window cap below the per-payment cap is refused (JV-08); `pause` by a stranger fails with `NotAuthorized` (JV-09); the behaviours below are documented in the code.
- **Bursar** (indexer, API, ABI): a job created on-chain by a different wallet than its owner signed in with is frozen, not opened (JV-02); the API refuses a window cap below the per-payment cap (JV-08).
- **Tests:** 54 contract tests (48 before), including a new invariant, "a closed job is owed nothing". Run against the original `JobVault.sol`, the new invariant, the post-close refund test and the window-cap check all fail (the fuzzer finds the stranded money within seconds); with the fixes they pass.
- **Wording:** the docs called the spending window "rolling". It is a fixed window; the docs now say so.

## Not deployed

The vaults already deployed (testnet `0x5Cd51a31fE931D31574Eadd083A0B5c210CA2cB6`, mainnet `0xE336a0A6a066336A5EFbb56542880da2EB87Df1B`) are immutable and run the previous code. The changes to the contract source (JV-01, JV-08, JV-09) take effect only in a new vault deployment. The off-chain changes (JV-02, JV-08 in the API) work with the vaults as they are.

## Coverage gaps the review listed

1. Post-close refund: tests added, and a new invariant.
2. Window boundary: a test shows the exact behaviour (JV-04).
3. `windowSpent` after a refund: a test documents it (JV-05).
4. `approvalThreshold = 0`: a test added (JV-07).
5. `windowCap < perTxCap`: tests added for `createJob` and `setLimits` (JV-08).
